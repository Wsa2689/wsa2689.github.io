🎊 What is Curved-Gauge-Card?

Curved-Gauge-Card is a free and easy-to-use tool that lets you add beautiful, animated gauges to your Home Assistant dashboard. If you have a smart home, you probably check things like temperature, humidity, energy usage, or other sensor data. Instead of seeing just plain numbers, you can now see everything in a colorful, easy-to-read gauge — just like the speedometer in your car!

This card was built for regular people, not just tech experts. You don't need to write complex code or understand programming. With simple settings and a clean design, anyone can make their dashboard look professional and polished in minutes.

🛠️ Step-by-Step Windows Installation Guide

1

Click the Download Button

Look for the green button above or scroll down to the download section at the end of this page. Click it to go to the official release page on GitHub.

2

Look at the Release Page

On the GitHub page, you'll see a list of files. Don't worry — GitHub looks scary but it's actually very easy. Look for the file with the highest number (that's the newest version) and click on it once to download it to your computer.

3

Find Your Downloaded File

Open the folder where your computer stores downloads (usually called "Downloads"). You'll see the file you just downloaded — it will have the name "Curved-Gauge-Card" or something similar.

4

Set It Up in Home Assistant

The downloaded file is simply a small package that you add to your Home Assistant. You'll go to Settings → Dashboards → Resources in your Home Assistant, and add this file as a new resource. There are clear prompts on the screen to guide you.

5

Add Your First Gauge

Once installed, you'll be able to add a new card to your dashboard. Click "Add Card" and search for "Curved Gauge". Then simply choose which sensor you want to display, and watch the magic happen!
